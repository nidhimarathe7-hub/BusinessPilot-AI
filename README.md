# BusinessPilot AI

An interactive business decision intelligence application built with Python and Streamlit.

## Features

- Business financial performance analysis
- Revenue, cost and profitability KPIs
- Expense breakdown visualization
- Business problem detection using financial rules
- Business strategy simulation
- Profitability comparisons
- Downloadable financial reports

## Technology Stack

- Python
- Pandas
- NumPy
- Plotly
- Streamlit

## How It Works

Users enter monthly revenue, cost of goods sold, salaries, rent, marketing expenses and other expenses.

The application calculates financial metrics, identifies potential problems, simulates alternative business scenarios and provides rule-based recommendations.

## Run Locally

Install the dependencies:

    pip install -r requirements.txt

Start the application:

    streamlit run app.py

## Important Note

BusinessPilot AI currently uses financial formulas and predefined decision rules. Its projections are hypothetical scenarios, not guaranteed outcomes or predictions from a trained AI model.
